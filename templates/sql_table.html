votes

Голоса пользователей за места

АтрибутТипОписание
PK idINTEGERУникальный идентификатор
FK place_idINTEGERСсылка на место
ip_addressVARCHAR(45)IP пользователя
created_atDATETIMEДата голосования
📌 Один IP может проголосовать за место только один раз

Связи между таблицами (IDEF1X)

categories ──◄ places (1:N)
categories ──◄ suggested_places (1:N)
places ──◄ votes (1:N)
Легенда:
PK — Первичный ключ
FK — Внешний ключ
● — Обязательный атрибут (NOT NULL)
◄── — Связь "один ко многим"
